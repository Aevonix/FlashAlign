# FlashAlign artwork

FlashAlign is an Aevonix Research product. The symbol is a segmented lightning
bolt, paired with an outlined uppercase wordmark. Its angular cuts and
amber/coral/teal accents share the Aevonix Spectrum visual language. All current
logo assets have transparent backgrounds.

All logo lettering is outlined. The SVG and PDF files contain vector paths;
they require no installed fonts, external images, scripts or network resources.
PNG exports preserve the alpha channel. Wordmarks are 3,200 px wide, icons are
2,048 × 2,048 px, and files carry 300 DPI metadata. SVG and PDF masters scale to
any resolution. The README uses a plain Markdown PNG image, without HTML image
tags, wrappers or URL query parameters. The lightning bolt and outlined
wordmark are together in the image; transparent space centers the complete
logo as the reader resizes it. Its tagline and subtext are native Markdown,
with no separately typed product-name heading. Mobile readers do not depend
on SVG or theme-switching support.

## Color and scale

| Color | Dark-surface ink | Light-surface ink |
| --- | --- | --- |
| Amber | `#FFB875` | `#A75322` |
| Coral | `#F59187` | `#A54E48` |
| Teal | `#76DCCB` | `#216B67` |
| Lettering | Warm ivory `#FFF1DD` | Graphite `#151615` |

The README variant uses bright amber, coral and teal with warm ivory lettering.
A fine graphite-green edge keeps those fills visible on light backgrounds.
The accent colors extend the Aevonix Spectrum palette. Use the dedicated
dark/light variants when the background is known.

The command-line interface uses a separate pixel drawing of the lightning mark
and lettering, stored in [terminal-logo.json](../../hermes-owner-mode/terminal-logo.json).
Its solid palette colors and grid-aligned edges stay sharp in terminals that
support Unicode blocks. Small or plain-text terminals use the product name as
text. The original vector and PNG artwork remains the source for graphical use.

Preserve proportions and leave at least one quarter
of the visible symbol height clear around the logo. Use the primary lockup at
360 px or wider, the compact lockup at 180 px or wider, and the standalone mark
at 24 px or larger. Use the compact lockup when the tagline would be too small.

The FlashAlign wordmark uses outlined Geist lettering. The font is not embedded
or redistributed; its [SIL Open Font License](Geist-OFL.txt) is retained here for
attribution. The original geometry is independent of the unchanged parent-brand
assets also retained in this directory.

The Aevonix name and supplied parent-brand artwork identify Aevonix Research.
Their proportions, colors and clear-space rules remain as supplied in the
[official brand package](https://aevonix.com/branding). The software license
does not grant trademark rights to either identity.
